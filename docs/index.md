## Pattern Categories

### Creational Patterns
Patterns for object creation and instantiation:
- Singleton, Factory Method, Abstract Factory
- Builder, Prototype

### Structural Patterns
Patterns for object composition and relationships:
- Adapter, Bridge, Composite, Decorator
- Facade, Flyweight, Proxy

### Behavioral Patterns
Patterns for object interaction and communication:
- Observer, Strategy, Command, State
- Template Method, Visitor, and more

## Language Support

All patterns are implemented in six programming languages:

- **C**: System programming and embedded systems
- **C++**: Object-oriented programming
- **Go**: Concurrent and modern system design
- **TypeScript**: Web development and type safety
- **Java**: Enterprise applications
- **Rust**: Memory-safe systems programming

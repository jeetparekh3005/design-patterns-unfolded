# Contributing to Design Patterns Unfolded

We welcome contributions to make this repository a comprehensive resource for learning design patterns through storytelling and multi-language implementations.

## How to Contribute

### 1. Fork and Clone
```bash
git clone https://github.com/jeetparekh3005/design-patterns-unfolded.git
cd design-patterns-unfolded
```

### 2. Create a Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Changes
- Follow the existing code structure and naming conventions
- Ensure all implementations compile and pass tests
- Update documentation as needed

### 4. Test Your Changes
```bash
./scripts/test-all.sh
```

### 5. Submit a Pull Request
- Provide a clear description of your changes
- Reference any related issues
- Ensure CI passes

## Contribution Guidelines

### Code Standards
- Follow language-specific style guides
- Include comprehensive tests for all implementations
- Add appropriate documentation and comments
- Ensure cross-platform compatibility

### Story Development
- Maintain consistency with the Kingdom of Gitlantis narrative
- Use clear, engaging storytelling techniques
- Include practical examples and use cases

### Pattern Implementation
- Implement patterns in all supported languages
- Include both basic and advanced examples
- Provide clear explanations of trade-offs and alternatives

## Development Setup

### Prerequisites
- C compiler (GCC/Clang)
- C++ compiler (GCC/Clang)
- Go 1.21+
- Node.js 18+ (for TypeScript)
- Java 17+
- Rust 1.70+

### Setup Script
```bash
./scripts/setup.sh
```

## Issue Guidelines

### Bug Reports
- Use the bug report template
- Include steps to reproduce
- Include expected vs actual behavior

### Feature Requests
- Use the feature request template
- Describe the use case and benefits
- Consider implementation complexity

### Pattern Stories
- Use the pattern story template
- Follow the established narrative framework
- Include character development and plot progression

This project follows the Contributor Covenant Code of Conduct. By participating, you agree to uphold this code.
